## Requirements

- R1–R4 are functional requirements and are implemented in the console application.
- R5: In a real deployment, authenticate users, use role-based access control, restrict medical records to authorized staff, and protect stored data.
- R6: In a real deployment, index availability data, keep queries efficient, and monitor response time to meet the two-second target.
- R7: In a web deployment, use responsive layouts and test common mobile screen sizes. The assignment permits a console application, so mobile UI is not implemented here.

## Run the application

Python 3.10 or newer is recommended. No third-party packages are required.

```bash
python main.py
```

Run the application's built-in demonstration:

```bash
python main.py --demo
```
